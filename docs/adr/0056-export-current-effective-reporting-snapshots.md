# Export current effective reporting snapshots

Organization Manager and Platform Administrator Report Exports use one asynchronous flow that captures current effective reporting facts in a transactionally consistent snapshot when generation starts. Ordinary CSVs expose correction markers rather than rewriting history invisibly, while a separately authorized correction-history export exposes prior and current values without actors or reasons; investigative identity and rationale remain in the filtered, append-only Audit Log. That separate authorization is a scope rather than a role: both reporting roles may request the correction-history extract, but an Organization Manager receives prior values only for revisions of facts its own Sponsorships covered when the fact occurred, so another Organization's Student and an unsponsored Student are absent from it rather than merely unlabelled. Marketplace-wide operational authority carries no such narrowing. The extract is requested, refused, audited, and scoped as its own decision instead of following automatically from access to the ordinary report. Exports require an explicit date range interpreted in the requester's Display Time Zone, bounded to at most 12 months and 25,000 rows; they never truncate, use a stable locale-independent schema, expire after 24 hours, and recheck authorization during generation and download. Historical as-of regeneration is deliberately excluded: an Audit Entry names the immutable Report Export record, which retains the acting role, filters, schema version, completion time, row count, and digest but never the exported content — the Audit Entry itself stays inside the fields ADR 0004 allows, so a later export truthfully reflects subsequent valid corrections.
