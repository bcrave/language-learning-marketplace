# Publish the portfolio under the MIT License

The source repository is public and MIT licensed so reviewers can inspect, run, and reuse the implementation. It includes the domain context, ADRs, roadmap, threat model, [operator and recovery runbooks](../operations/operator-guide.md), GraphQL schema, SQL migrations, tests, CI, and [fictional fixture definitions](../fixtures/synthetic-curriculum-manifest.md) plus the deployed-demo link. It excludes environment files, database dumps and backups, provider or deployment credentials, real personal data, and copied proprietary course content. Public source visibility is treated as a design constraint rather than a secrecy-based security control.
