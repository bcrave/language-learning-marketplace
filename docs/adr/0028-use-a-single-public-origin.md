# Use a single public origin

A Caddy service is the deployment's only public application origin. It serves the built Vite SPA, routes application paths to the SPA entry point, proxies `/graphql` through Railway private networking to the GraphQL API, establishes verified source-address context, and owns the deterministic global browser-security headers defined by the [public portfolio threat model](../threat-model.md). The API has no independent public address, exposes no cross-origin CORS policy, and accepts forwarded source context only from Caddy; the worker remains non-HTTP. This removes cross-origin browser configuration, reduces the public network surface, and gives Auth0 one application callback origin at the cost of a small additional routing layer and an accepted availability choke point. How the API recognizes that context as Caddy's, and what happens when it is absent, is decided in [ADR 0058](0058-authenticate-forwarded-source-context.md).
