# Build the UI from shadcn, Tailwind, and Radix

The Vite React app uses shadcn/ui component source styled with Tailwind CSS v4 and backed by Radix Primitives for complex interaction behavior. This provides a polished, customizable starting point while keeping component code inside the repository and relying on mature keyboard, focus-management, and ARIA primitives. Native HTML remains preferred when sufficient, and the components do not waive the project's WCAG 2.2 AA testing requirements.
