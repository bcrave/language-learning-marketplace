# Keep Cohort membership changes prospective

A Cohort membership begins no earlier than the instant it is recorded and ends no earlier than the instant it is ended, so an Organization Manager can never backdate or retroactively shorten one. Membership windows are half-open: activity exactly at an end instant already falls outside. Ending a Sponsorship closes its still-open memberships at the same instant, because a Cohort only organizes reporting the Sponsorship authorizes.

The alternative was to let a manager correct membership history, which would silently rewrite the Cohort attribution of activity that earlier reports already showed. Rejecting backdating keeps [ADR 0047](0047-snapshot-organization-visible-progress.md) enforceable: attribution follows the membership effective when the Class Session occurred, and only an Attendance correction may revise a historical reporting fact. It also matches the accepted Sponsorship rule that the relationship cannot be backdated and ends only prospectively. The cost is that a manager who forgets to record a membership cannot recover the missing attribution; they add the Student now and the earlier period stays unattributed.
