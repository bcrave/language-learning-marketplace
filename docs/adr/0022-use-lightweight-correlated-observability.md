# Use lightweight correlated observability

The deployed demonstration emits privacy-filtered structured JSON logs with Pino to Railway and reports unexpected browser and server failures plus selected traces to hosted Sentry. The API exposes separate liveness and readiness checks; readiness verifies PostgreSQL access and schema compatibility. The worker records a PostgreSQL heartbeat surfaced through an owner-only diagnostics view. A correlation identifier follows each operation through GraphQL, database transactions, durable events, worker attempts, notification intents, Audit Entries, logs, and error reports. Authentication secrets, contact details, private feedback, and complete GraphQL variables are excluded. This provides application-level diagnostics within the portfolio budget without operating an OpenTelemetry collector.
