# Separate public client configuration from secrets

Runtime secrets live in least-privilege Railway service variables, PostgreSQL uses a private Railway reference variable, and GitHub's protected production environment holds only an environment-scoped deployment token. Local overrides use ignored `.env.local` files while a committed `.env.example` contains safe placeholders, and Zod rejects incomplete startup configuration. Values embedded by Vite—including Auth0 domain and client ID, API audience, and browser Sentry DSN—are classified as public. Client secrets, management tokens, database credentials, deployment tokens, server monitoring credentials, and signing material never enter the frontend build. Secret scanning and push protection are enabled, and exposure requires revocation rather than repository-history cleanup alone.
